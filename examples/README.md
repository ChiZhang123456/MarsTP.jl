# MarsTP examples

| Directory | Contents |
| --- | --- |
| [background_models](background_models/README.md) | MHD, GITM and AMPS fields, moments and atmospheric maps |
| [forward_tracing](forward_tracing/README.md) | Spherical release, forward trajectories and electric work |
| [backward_tracing](backward_tracing/README.md) | Detector backtracing, source derivation and preliminary integrated VDFs |

Each directory contains documentation, integration or plotting scripts, and images. Physical inputs are stored in `data/`; complete runs are stored locally in `outputs/`. Run commands from the repository root. See each directory for dependencies.

The preliminary backward VDF has not converged with respect to velocity spacing and time step.
