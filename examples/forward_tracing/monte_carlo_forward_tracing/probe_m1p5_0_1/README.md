# O₂⁺ probe (-1.5, 0, 1) Rm

![Velocity-integrated VDF](probe_psd_projections.png)

探头中心 **(-1.5, 0, 1) Rm**，立方体边长 **0.2 Rm = 678 km**。从同一次 500 km 源面模拟的完整轨迹提取驻留时间，不重新采样或传播粒子。

先建立各轴 **−500 到 500 km/s、1 km/s 宽度**的三维 PSD，单位 **s³/m⁶**，再将被省略速度轴全部积分：`fxy = sum_z(f3d)*1000 m/s`，`fxz = sum_y(f3d)*1000 m/s`。图中单位为 **s²/m⁵**。坐标显示沿用 ±300 km/s，包含本探头全部速度贡献；turbo、对数色标、无平滑、无零速度切片。

| 量 | 结果 |
| --- | ---: |
| 密度 (m⁻³) | 117721.665 |
| 密度 (cm⁻³) | 0.117721665 |
| 独立命中粒子 | 2,011 |
| 驻留权重有效样本数 | 353.706 |
| 驻留段 | 124,374 |
| 穿面事件 | 4,042 |
| 非零三维 bin | 36,733 |

[三维稀疏 PSD 和二维投影](probe_psd_sparse.npz) 保存完整 1000³ 网格的非零值及零基索引，未列出的 bin 是本次抽样的零值。另见 [完整统计和速度范围](analysis_summary.json)。三维积分与两个二维积分都复现同一驻留时间密度。

复现步骤见 [上一级 README](../README.md#已保存轨迹上的三个探头)，分析单个提取结果的命令为：

```powershell
& $py "$example/analyze_probe.py" "$reprobe/probe_m1p5_0_1" --output-dir "$reprobe/probe_m1p5_0_1/analysis"
```

本结果采用原生 MHD 笛卡尔轴，最大飞行年龄 500 s，尚未证明稳态收敛。不同探头图的色标独立归一化，跨图比较请读取数值。
